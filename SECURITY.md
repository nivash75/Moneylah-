# Security

## Supported versions

Fixes go into the latest release only.

## Report a vulnerability

Do not post details in a public issue.

Use **Report a vulnerability** under the repository's [Security tab](https://github.com/tnivash/Moneylah-/security). If that button is not there, open an issue that only asks for a private way to get in touch, with no details.

Never send real financial records, backup files, or your Google Sheets link or key.

## What the app protects

See [Data and privacy](README.md#data-and-privacy). The app lock hides the screens; it does not add encryption beyond what iOS provides, and backup and export files are not encrypted.
